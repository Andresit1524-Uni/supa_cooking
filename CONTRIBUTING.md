# Guía de contribución

## Manejo del repo
El repo se manejará por ramas las cuales luego se envían a la principal por medio de una pull request. El proceso es el siguiente:

1. Tu rama debe tener la convención `nombre-tarea`, todo en minúscula y sin tildes (por ejemplo `andres-pilas` o `jeison-musica`)
2. Las ramas luego se fusionan hacia el `main`, usando **siempre un pull request**
3. Las extensiones "Git Graph Plus" y "GitHub Pull Requests" te ayudarán en el proceso
4. Solo el dueño del repo (@Andresit1524) puede hacer commits directos al `main`
5. De la misma manera, @Andresit1524 (y quizas @DanielADuranC) se encargan de fusionar correctamente los cambios y arreglarlos, así como de testear y exportar el juego
6. El informe se puede hacer en el mismo repo, en la carpeta `docs/`

Se hará una revisión grupal para saber quien hace que: no se improvisa.

## Convenciones de programación
1. Usa las convenciones de nombre oficiales de cada lenguaje. Puedes encontrarlas en internet
2. No existe un estándar de estilo de lógica de código, pero sé consistente con el tuyo. 
3. También puedes seguir la [guía de estilo de GDScript](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html)
4. [C# tiene su guía también](https://docs.godotengine.org/en/stable/tutorials/scripting/c_sharp/c_sharp_style_guide.html)
5. El código (clases, variables, valores) va en inglés, los comentarios en español. [Guía de nombres](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html#naming-conventions)
6. Archivos y carpetas en inglés. [Guía de nombres](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html#file-names)
7. Nodos en inglés. [Guía de nombres](https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_styleguide.html#classes-and-nodes)
8. El juego también está en español
9. Usa nombres descriptivos y una lógica clara
10. Si requieres muchos comentarios o mucha memoria, reconsidera
11. Usa un formateador. Puede ser el de godot-tools o el GDQuest, y para C# también
12. Pide feedback, especialmente a los admins del proyecto (@Andresit1524 y @DanielADuranC)
13. Sigue las convenciones de nombres de Godot
